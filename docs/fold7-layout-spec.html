Design Critique & Comparison Matrix

Evaluation Criteria Option 1: Classic Top Tabs Option 2: Utility Flank Option 3: Thumb Shelf (Default) ★
Fold7 Cover Screen Ergonomics Poor. Top tab bar forces index-finger reach to top bezel while typing at bottom. Moderate. Requires edge swipe from bezel which conflicts with Android back gesture. Superior. 100% thumb reachable. Bottom shelf anchors session sheet & modifiers together.
Terminal Lines Visible (IME Open) 11 lines (Top tab bar + Top action row + Keyboard + Modifier strip eats height). 16 lines (Hidden chrome, but reveals layout jitter when summoned). 17 lines. Pure terminal output from row 0 down to the single 48dp modifier strip.
48dp Target Compliance Mixed. Squeezing tabs into phone top bar often leads to 32dp micro-targets. Pass on keys, but edge swipe handles are narrow (24dp strip). 100% Strict Pass. Every key, toggle, and sheet item has min 48×48dp bounding box.
Fold / Unfold Continuity Awkward. Top tab bar must reposition to a left column upon opening device. Moderate. 56dp icon rail expands into desktop sidebar. Natural. Bottom sheet auto-promotes into persistent 260dp left rail when width ≥ 700dp.
User Choice in Settings Configurable as "Classic Tabs" layout preference in Settings. Configurable as "Full-Screen Canvas" preference in Settings. Default layout, with instant live switching across all 3 options.

Settings Architecture & Jetpack Compose Wiring

Giving power users the ability to choose their layout mode in Settings requires only a small, clean extension to WorkspacePrefs.kt and AiUi.kt: 

// 1. WorkspacePrefs.kt — Navigation & Layout Preferences
enum class PhoneNavStyle(val key: String) {
    THUMB_SHELF("thumb_shelf"),   // Option 3: Zero top chrome, bottom sheet (default)
    CLASSIC_TABS("classic_tabs"), // Option 1: Top horizontal tab bar
    FULL_CANVAS("full_canvas")    // Option 2: Pure fullscreen with edge summon
}

enum class WideRailMode(val key: String) {
    ADAPTIVE("adaptive"), // 240dp full sidebar collapsible to 60dp
    COMPACT("compact")    // Fixed 60dp icon strip
}

object WorkspacePrefs {
    fun phoneNavStyle(ctx: Context): PhoneNavStyle =
        PhoneNavStyle.values().firstOrNull { it.key == prefs(ctx).getString("phone_nav_style", "thumb_shelf") } ?: PhoneNavStyle.THUMB_SHELF

    fun setPhoneNavStyle(ctx: Context, style: PhoneNavStyle) =
        prefs(ctx).edit().putString("phone_nav_style", style.key).apply()

    fun touchTargetDp(ctx: Context): Int = prefs(ctx).getInt("touch_target_dp", 48)
    fun setTouchTargetDp(ctx: Context, dp: Int) = prefs(ctx).edit().putInt("touch_target_dp", dp).apply()
}

// 2. MainActivity.kt — Declarative Layout Selection
val isWideScreen = LocalConfiguration.current.screenWidthDp >= 700
val navStyle = remember(prefsUpdateTrigger) { WorkspacePrefs.phoneNavStyle(ctx) }
val targetDp = remember(prefsUpdateTrigger) { WorkspacePrefs.touchTargetDp(ctx).dp }

Row(Modifier.fillMaxSize()) {
    if (isWideScreen) {
        // Unfolded Inner Screen: Left Rail
        WorkspaceSidebar(collapsed = workspaceCollapsed, targetDp = targetDp)
    }

    Column(Modifier.weight(1f).fillMaxHeight()) {
        // If user chose Classic Tabs on phone:
        if (!isWideScreen && navStyle == PhoneNavStyle.CLASSIC_TABS) {
            TopTabStrip(sessions = sessions, activeIndex = activeIndex)
        }

        // Terminal Output Screen
        TerminalCanvas(Modifier.weight(1f))

        // Modifier Strip (Unified 48dp)
        TerminalModifierStrip(
            navStyle = navStyle,
            isWideScreen = isWideScreen,
            height = targetDp,
            onOpenDrawer = { bottomSheetOpen = true }
        )
    }
}

// 3. Bottom Sheet for Thumb-Reach Mode
if (!isWideScreen && navStyle == PhoneNavStyle.THUMB_SHELF && bottomSheetOpen) {
    ModalBottomSheet(onDismissRequest = { bottomSheetOpen = false }) {
        WorkspaceDrawerContent(sessions, onSelect = { /* switch tab */ })
    }
}
