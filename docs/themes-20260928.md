# Pocket Shell 0.5.0: whole-app themes

The earlier theme picker changed ANSI text but left the app and translucent terminal backdrop unchanged. This release replaces fixed chrome colors with scoped Compose theme roles and explicitly paints the native terminal background. The selected theme also controls dialogs, key controls, and Android system bars. The window is opaque so phone wallpaper cannot reduce text contrast.

The picker offers twenty previews, text search, All/Dark/Light/OLED filters, an empty-search recovery action, and direct selection from either the workspace or Settings. A lazy adaptive grid fits narrow phones, landscape, and unfolded devices. Close remains outside the scrolling catalog.

The portable JSON source generates Android and CSS adapters. Existing palette IDs, preferences, ANSI colors, foreground service sessions, and SSH data are retained. Recoloring resets emulator palettes in place and uses the existing history-preserving redraw path. Startup loads the saved palette before the terminal service can create a session.

## Verification

The catalog validator checks role contrast and adapter freshness. Unit tests cover complete terminal palettes, historical preferences, fallback, and search. The hosted Android UI fixture drives all twenty themes with two live PTYs, checks native background and ANSI values in both sessions, reads back the saved selection, recreates the Activity, and verifies history remains anchored. It captures actual app screenshots at 360 dp, landscape, and 800 dp unfolded widths, and exercises filters, empty-search recovery, and the Settings entry point. The existing terminal, input, and workspace tests remain release gates.

Physical-phone installation and ARM64 SSH acceptance are separate from hosted emulator proof. Publishing an APK must not force-stop the user's active terminal session.
